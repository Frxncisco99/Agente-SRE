# Agente-SRE
Este sistema es un Early Warning System (EWS) para SRE/AIOps. Su misión no es esperar a que un servidor se caiga para alertar, sino predecir la caída horas antes analizando tendencias matemáticas sutiles (precursores) y filtrar falsas alarmas (señuelos) usando un LLM con el contexto del negocio.
